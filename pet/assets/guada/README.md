# 呱搭 · Guada 素材模板

Guada 是摸鱼哨的可选伙伴。此目录的公开版本仅提供 manifest.json，
不附带未经确认分发授权的图片、动画、原始照片或录屏。
本机已有素材不因发布整理而删除。

把有权使用的素材放到此目录，编辑 UTF-8 manifest.json 的 states 映射：
working、waiting、error、idle。可用静态 PNG/JPEG 或 GIF。
文件须直接位于此目录，每个小于 10 MB；桌宠读取限制为 400 万像素。
不要把目录指向网络资源或可执行代码。缺失/损坏素材时仍有文字回退。
建议短循环、适度帧率；隐藏时由渲染器暂停，不反复加载。
代码许可不自动覆盖角色形象或图片版权。分发自定义素材前自行确认授权。
